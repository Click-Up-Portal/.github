# Click Up Portal - One Board for Tasks You Already Own

## First Look at Click Up Portal

Click Up Portal is a board for tasks you already own. ClickUp shows the same rows when you come back. Click Up is not a second product. It is that board: a name, a date, and a done mark.

Students, freelancers, and small teams can use it differently, but the habit stays the same. One list. Real dates. No pile of unnamed notes.

## Quick Start with Click Up Portal

1. **Open Click Up Portal** - Use the account you already sign in to.
2. **Name one task** - Write the thing you will actually do.
3. **Add a date** - Leave it blank only if there is no real deadline.
4. **Keep the board short** - Hide rows that are not this week.
5. **Mark done** - Move finished work off the live list.
6. **Reopen** - Start the next day from the same ClickUp board.
7. **Stop** - Do not add a second board for the same job.
